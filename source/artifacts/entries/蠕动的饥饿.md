“蠕动的饥饿”是一只薄如人皮的神奇手套，以活人的血肉和灵魂为食，具有类似“牧羊人”的放牧能力。它能变透明、伪装成皮肤或不同颜色的手套，未使用时不易被多数非凡手段察觉。（《诡秘之主》第一卷第146章、第190章；《诡秘之主》第三卷第7章）

## 放牧能力

[齐林格斯](../../../characters/entries/齐林格斯/)持有时期，手套最多放牧五个灵魂，一次只能驱使一个，切换至少需要一秒。每个灵魂随机提供一至三种生前能力，初次放牧后固定；佩戴者仍能使用自身能力。替换原有灵魂不可逆。（《诡秘之主》第一卷第190章）

克莱恩取得时，五个灵魂为“无面人”“心理医生”“审讯官”“梦魇”和“光之祭司”，分别提供变貌、精神影响、武器与爆破运用、入梦、净化与神圣之光等能力。“梦魇”由手套完成入梦，佩戴者自身仍能移动。（《诡秘之主》第二卷第268章）

在灰雾之上，克莱恩能释放灵魂，使其解脱并留下非凡特性；在现实世界，被释放的灵魂会遭手套吞食，再吐出特性。（《诡秘之主》第三卷第1章）

## 迷雾小镇后的异变

手套与A先生及蘑菇糅合后，放牧上限变为七个灵魂，每次获得两至三种能力，其中一种可由佩戴者选择。切换加快，手套自身获得“藏入阴影”“血肉炸弹”，有机会勉强放牧一位序列4圣者。（《诡秘之主》第四卷第111章–第113章）

当时八个灵魂造成挤压、部分能力无法使用；释放“安魂师”后，剩余七个为：

| 灵魂 | 当时可用能力 |
| --- | --- |
| 腐化男爵米索尔 | 扭曲、贿赂—削弱、腐蚀；腐蚀影响周围十米内的心灵。 |
| 欲望使徒[吉尔希艾斯](../../../characters/entries/吉尔希艾斯/) | 预知危险、[污秽之语](../污秽之语/)—缓慢、岩浆之剑；预知危险需提前开启并保持该灵魂状态。 |
| 旅行家[路易斯·维恩](../../../characters/entries/路易斯·维恩/) | 旅行、开门、变异的记录；只能记录半神能力，最多两个，不高于序列3，仍需反复尝试。 |
| 活尸[麦维提](../../../characters/entries/麦维提/) | 活尸力量、冰的掌控、操纵活尸。 |
| 痛苦魔女 | 魅惑及一定外貌调整、近五十米范围的疾病；感染随时间加重。 |
| 风眷者 | 短途飞行、深潜、控水。 |
| 医生 | 分辨天时、治疗恶疾、缝合灵魂。 |

其中“预知危险”替换了此前的“硫磺火球”；这些是异变后当时固定的能力组合。（《诡秘之主》第四卷第113章）

## 饥饿与封印

齐林格斯时期，每隔一天须喂食一个活人的血肉和灵魂，否则吞噬主人。[阿兹克](../../../characters/entries/阿兹克·艾格斯/)第一次封印后，平时不再饥饿，使用后仍需进食；经过磨合，克莱恩可在使用当天二十四小时内反复使用、只喂一次，未使用的日子无需喂食。（《诡秘之主》第一卷第146章；《诡秘之主》第二卷第267章；《诡秘之主》第三卷第147章）

迷雾小镇异变后，它恢复每天吃一个活人的要求，并随机赞颂“[真实造物主](../../../characters/entries/真实造物主/)”，导致思绪混乱、头痛；五米内出现蘑菇时，所有能力都无法使用。克莱恩以蘑菇迫使它同意在早、中、晚餐时赞颂并预先提醒，但未能消除喂食需求。（《诡秘之主》第四卷第113章、第131章）

阿兹克随后借冥界力量再次封印，使效果恢复“和以前一样”。此前以蘑菇遏制饥饿只能暂时压制，蘑菇消失后可能立即反噬。（《诡秘之主》第四卷第163章、第181章）

## 流转与后续状态

齐林格斯死后，阿兹克取得手套，封印后交给[克莱恩](../../../characters/entries/克莱恩·莫雷蒂/)。复活广场一战后，[伦纳德](../../../characters/entries/伦纳德·米切尔/)通过[蕾妮特](../../../characters/entries/蕾妮特·缇尼科尔/)将手套送还。[奥黛丽](../../../characters/entries/奥黛丽·霍尔/)也曾借用它传送，完成任务后献祭归还。（《诡秘之主》第一卷第192章；《诡秘之主》第二卷第267章；《诡秘之主》第五卷第2章、第150章、第152章–第153章）

克莱恩在[神弃之地](../../../worldview/countries/entries/神弃之地.html)的战斗与自杀后失去手套，实物落入[阿蒙](../../../characters/entries/阿蒙/)手中。后来的克莱恩使用历史影像，包括容纳“愚者”唯一性前的准备；在“暗天使”沉睡之地，影像也曾因堕落影响试图反噬，被[“星之杖”](../0-62/)的位格压制。（《诡秘之主》第六卷第21章、第110章；《诡秘之主》第八卷第6章、第20章–第21章）

## 待核事项

阿兹克第二次封印后的异变残留情况不详。
阿蒙身旁后来被丢弃、表现满足的人皮手套，与此物的同一性及后续去向不详。（《诡秘之主》第八卷第34章）
