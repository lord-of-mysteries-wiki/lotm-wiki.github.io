“大地的恩赐”是白银城保存的“0”级封印物，为巨人王后[欧弥贝拉](../../../characters/entries/欧弥贝拉/)的尸骸。外形是一截七八米高的枯萎巨树，呈灰褐色，树心中空，树干上有人形轮廓，以枝丫为手、两朵绯红巨花为眼，木纹间隐现血色。（《诡秘之主》第六卷第116章；《宿命之环》第六卷第6章–第8章）

## 能力

| 作用 | 范围与限制 |
| --- | --- |
| 创造食物 | 在任何环境中创造可食植物，促进其在五十公里内生长、繁育与丰收；黑面草是白银城的重要食物。 |
| 改善环境 | 三百公里内土地变肥沃、水流变充沛、繁衍倾向增强；恶劣环境只能降低繁育数量与频率。也能改造环境，使深渊适于人类生存。 |
| 凋零生命 | 主动使用时，使三十公里内生命迅速流逝至死亡；相似领域外的能力也逐渐凋零、削弱，亡者会快速回归大地。 |
| 改变区域 | 五十公里内布满剧毒、长出有利于自身的超凡植物，驯化无高等智慧的动物，并加剧非凡者的失控倾向。 |
| 制造人偶 | 触碰泥土、植物、岩浆、矿石或金属，制造具备生命与力量的人偶；最高不超过序列3，半神层次最多九个。 |
| 融入环境 | 持握者与范围内的大地、树林、水流、山峰及矿石等融为一体，可借其穿梭，速度因媒介而异。 |
| 攻击 | 被击中者同时承受失控与死亡考验，无法通过便会失控或死亡。 |
| 改变持握者 | 可短暂变为神话生物，须自行承受相应知识与疯狂意念冲击；也能使持握者具备全部女性特征。 |

以上能力记载以白银城的经验与认知为范围。（《诡秘之主》第六卷第116章；《宿命之环》第六卷第6章–第7章）

## 使用风险与封印

五十公里内的人类死者会变为恶灵，死于直系亲属之手者除外；食用过它创造的食物、与之存在强联系的人，在三百公里内死亡也受此影响。它还会随机使三百公里内土地荒芜、粮食绝产、植物凋零；荒芜结束前土地无法恢复肥沃，天使层次的净化类能力可以将影响压制在很小范围内。

触碰者可能被治愈全部伤病，也可能瞬间死亡，结果无法事先占卜。预言中，拥有欧弥贝拉血脉且遭受过直系亲属背叛的女性不会瞬间死亡；不满足条件者即使得到治愈，也不能使用超过一分钟，否则会失控或死亡。满足条件者仍会承受其他负面影响。

不具神性者仅了解相关资料，就有较大概率感而受孕、怀上未知生物。拥有神性也不能保证接触安全：[卢米安](../../../characters/entries/卢米安·李/)接触并短暂举起树干后，同样出现感而受孕的迹象，随即以黑焰清除。（《宿命之环》第六卷第6章–第8章）

白银城以[“荣耀之证”](../荣耀之证/)压制它及其他封印物。（《诡秘之主》第七卷第84章；《宿命之环》第八卷第33章）

## 流转与毁坏

白银城长期凭它生产黑面草，也长期承受亲属间弑杀的诅咒。[科林](../../../characters/entries/科林·伊利亚特/)临终前将尸骸的秘密告诉[戴里克](../../../characters/entries/戴里克·伯格/)。（《诡秘之主》第六卷第116章）

末日战前，戴里克以它交换“[绯红之灾](../绯红之灾/)”。吉达斯将其带入卢米安的神国——毁灭后重生的特殊镜中世界。随后，遗骸与[莉莉丝](../../../characters/entries/莉莉丝/)重叠，被卢米安以“毁灭之剑”一同斩击；遗骸化为焦黑木块，欧弥贝拉残存的精神与灵性消弭。这场牺牲利用身份与象征联系，激发母巢对堕落母神的反抗。（《宿命之环》第八卷第33章–第35章）

卢米安从碎块中提取“荒芜主母”的恩赐，聚合为长着青草、谷物与藤蔓的褐色泥土，交吉达斯带给[奥黛丽](../../../characters/entries/奥黛丽·霍尔/)。残余力量不再具有欧弥贝拉的身份及相应联系，只保留少量母巢的意识与精神，无法稳定补充力量，使用一次便消耗一部分。（《宿命之环》第八卷第36章）
